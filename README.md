# Repository: 24730162_oop_dsa

Welcome to the organized repository for OOP and DSA coursework. This project has been restructured for better readability and maintenance.

## 📂 Directory Structure

### [DSA (Data Structures and Algorithms)](./DSA)
- **Projects/**: Comprehensive projects (e.g., Student Management).
- **BST/**: Binary Search Tree implementations.
- **list/**: Linked list exercises and applications.
- **baitapquanlysinhvien.cpp**: Procedural implementation (Struct-based) for student management.

### [OOP (Object-Oriented Programming)](./OOP)

### [IntroProgramming (NMLT)](./IntroProgramming)
- **Exams/**: Solutions to previous exams and tests.
- **Labs/**: Laboratory exercises covering arrays, strings, and matrices.
- **Misc/**: Weekly exercises (Buoi 1-4) covering basics, pointers, and structs.
- **pointer_exercises.cpp**: Consolidated exercises on pointers and dynamic memory.

### [Python](./Python)
- Basic Python scripts and projects.

### [Docs](./Docs)
- Academic reports and project documentation.

## 🚀 Optimization Highlights
